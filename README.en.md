# calculator Dropshipping — profit, CPA & ROAS | piercer

cost of fornecedor, gateway, checkout, tax, CPA máximo and ROAS of empate

## Features

- **Main Sections**: Composição of sale, simulator of Escala & Capital of Giro
- **Available Actions**: reset, PDF, copy summary
- **Auto-Save**: automatically persists changes in the browser (`localStorage`).
- **Multi-Language**: built-in language switcher (`PT / EN / ES`).
- **Print / PDF**: A4-optimized print layout via `@media print`.

## How to Run

1. Run `start.bat` to start the local server on port `8105`, or open `index.html` directly in your browser.
2. Open `http://localhost:8105`.
