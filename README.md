# Calculadora Dropshipping — Lucro, CPA & ROAS | piercer

Custo do fornecedor, gateway, checkout, imposto, CPA máximo e ROAS de empate

## Funcionalidades

- **Seções principais**: Composição da Venda, Simulador de Escala & Capital de Giro
- **Ações disponíveis**: Resetar, PDF, Copiar resumo
- **Persistência automática**: salva alterações automaticamente no navegador (`localStorage`).
- **Multilíngue**: suporte integrado com botão de troca de idioma (`PT / EN / ES`).
- **Impressão / PDF**: layout otimizado em folha A4 via `@media print`.

## Como Executar

1. Execute `start.bat` para iniciar o servidor local na porta `8105`, ou abra `index.html` diretamente no navegador.
2. Acesse `http://localhost:8105`.
